# Vantage Airlines App

Aplicación oficial de Vantage Airlines, aerolínea virtual. Aquí se publican las versiones oficiales de la app en formato APK para dispositivos Android.

## Descarga

Ve a la sección [Releases](https://github.com/UrafaelGames/Vantage-Airlines-App/releases) y descarga el archivo `.apk` de la versión más reciente.

> La app no está disponible en Google Play. Debes habilitar la instalación de apps de fuentes desconocidas en tu dispositivo Android para instalarla.

## Instalación

1. Descarga el `.apk` desde la última release.
2. Abre el archivo descargado desde tu explorador de archivos o notificaciones.
3. Si Android te lo pide, autoriza la instalación desde fuentes desconocidas para esta app.
4. Sigue los pasos del instalador.

## Actualizaciones

La app verifica automáticamente si hay una nueva versión disponible al abrirse. Las actualizaciones importantes (seguridad o cambios mayores) son obligatorias; el resto son opcionales y puedes posponerlas.
